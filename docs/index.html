Features

Built for the local network, not the cloud.

  • Zero setup

    Single binary for your OS. No Node, no runtime, no installer dance.

  • Serverless & private

    Pure peer-to-peer UDP. Nothing leaves your LAN. No accounts, no telemetry.

  • Auto-discovery

    Peers on the same Wi‑Fi just appear. Heartbeats in, prune out — no directory.

  • Your name, your call

    Pick a username on first run. Change it anytime with /nick.

  • Cross-platform

    Windows, macOS, and Linux — same LAN, mixed machines, one protocol.

  • Open source (MIT)

    Read it, fork it, ship it. Free forever under the MIT license.

How it works

Three steps. Same Wi‑Fi. Done.

  1. 01

    Download the binary

    Grab the build for Windows, macOS, or Linux. No Node for end users.

  2. 02

    Run it & pick a username

    First launch asks for a name, then you’re on the LAN.

  3. 03

    Peers appear — start chatting

    Anyone else on the same Wi‑Fi running LANterm shows up automatically.

Network permission: allow local/UDP access on first run (Windows Firewall → Allow on Private networks; macOS local network prompt; Linux firewalls → UDP 47474). Otherwise peers won’t discover you.

Quick start

Install & run

Download (Windows x64) 
curl -L https://github.com/yash-js/lanterm/releases/latest/download/lanterm-windows-x64.exe -o lanterm.exe
.\lanterm.exe

On a corporate / locked-down network and hitting a schannel revocation error? Add --ssl-no-revoke (curl --ssl-no-revoke -L …), or download from the Releases page.

Download (macOS Apple Silicon) 
curl -L https://github.com/yash-js/lanterm/releases/latest/download/lanterm-darwin-arm64 -o lanterm
chmod +x lanterm
./lanterm

Intel Mac? Use lanterm-darwin-x64 instead.

Download (Linux x64) 
curl -L https://github.com/yash-js/lanterm/releases/latest/download/lanterm-linux-x64 -o lanterm
chmod +x lanterm
./lanterm

ARM64? Use lanterm-linux-arm64 instead.

Build from source (any OS) 
git clone https://github.com/yash-js/lanterm.git
cd lanterm
npm install
npm run build:win        # or build:mac / build:linux / build:all

How to use?

Type lanterm. Start chatting.

On first run LANterm adds itself to your PATH. After that, just open any terminal — Terminal, PowerShell, or your shell — and run one word:

Any terminal 
lanterm
  1. 01

    Run lanterm

    Open your terminal, type lanterm, and press Enter.

  2. 02

    Pick a username

    First launch asks for a name — it’s saved for next time.

  3. 03

    Type & hit Enter

    Your message reaches everyone on the same Wi‑Fi. Peers show up automatically.

Handy slash commands while you’re in a chat:

/nick <name>
Change your username — saved and announced to peers.
/peers
List everyone currently online on your network.
/clear
Clear the message feed in your terminal.
/update
Check GitHub for a newer LANterm release.
/update install
Download and apply the latest release, then restart.
/help
Show the list of available commands.
/quit · /exit
Say goodbye to peers and leave the chat.
